## Zadatak
Ti NISI pisao ovaj kod — radiš kao strogi, nezavisni recenzent. Pregledaj ceo run: `git log main..HEAD`,
`git diff main...HEAD --stat`, `docs/CREA-PROGRESS.md`, svi planovi u `docs/crea/planovi/`.
Proveri i prijavi (sa putanjom:linijom):
1. Bezbednost i vlasništvo: svaka nova Convex funkcija proverava prijavu i vlasništvo; nema curenja tuđih radova;
   limiti za lokalne rezultate; flegovi stvarno sakrivaju ono što treba.
2. Novac: nijedna cena se nije promenila dok je `crea_pricing_v2` isključen; nema duplih povraćaja; noćna tura je
   idempotentna; nagrade se ne mogu farmati.
3. Rute i SEO: stari `/studio` linkovi rade (308), nema polomljenih linkova, sitemap.
4. Licence: nijedan paket iz §6, svaki novi paket je na listi §5; CC0 fajlovi imaju izvor.
5. Bundle: teške biblioteke samo dinamički na `/crea`.
6. UI pravila: radiusi, okviri, tokeni, i18n (nema hardkodovanog teksta), obe teme, telefon, `prefers-reduced-motion`.
7. Funkcionalno: šta iz §7 plana radi, šta je „uskoro", šta je polomljeno.
8. Pokreni `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build` i `npm run check:frames` i
   `npm run check:corners` — prijavi rezultate (ovo je čitanje, ne izmena).
Izlaz: izveštaj sa nalazima rangiranim po ozbiljnosti (KRITIČNO / VAŽNO / SITNO) i za svaki tačan predlog popravke.
