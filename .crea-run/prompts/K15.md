# K15 — Recepti, brend kit, serije, nalepnice, logo, 3D
Režim: **goal** · Effort: **high** · Sesija: **nova** · Model: Opus 5.5
Feature ID-jevi: S37–S42

Pre rada pročitaj: `.crea-run/rules.md` (obavezno, važi uvek), `docs/CREA-PLAN.md` (§7.1), `docs/CREA-PROGRESS.md`.
Ako `git status` pokazuje delimičan rad iz prekinutog pokušaja OVOG koraka, nastavi ga — ne kreći ispočetka. Ako je nešto iz ovog koraka već urađeno u ranijem koraku, nadogradi ga, ne dupliraj.

## Zadatak
- S37 Recepti: ~20 srpskih recepata (podaci po planu K01): profilna, CV fotka, foto-dump tvog lika, jelovnik za
  kafić, oglas za stan, pozivnica za slavu i rođendan, bojanka za decu, logo, thumbnail, plakat, proizvod na belom,
  proizvod u ambijentu, Viber nalepnice, „stara fotka" itd. Svaki: 2–3 polja, primer, FIKSNA cena izračunata iz
  kataloga, sledeći koraci. Kartice „Šta praviš danas?" (K03) sada vode u recepte.
- S38 Brend kit: logo, boje (izvučene iz logoa — `colorthief`), fontovi, ton; automatski u receptima, tekstu i
  vodenom žigu.
- S39 Serije: jedan proizvod × lista tekstova/formata → više poslova odjednom (ponudi noćnu turu ako postoji).
- S40 Viber/WhatsApp nalepnice: 9 izraza lika u jednoj slici 3×3 → isečeno, bez pozadine (lokalno), 512×512 WebP,
  preuzimanje paketa; sprajt-list za igricu iz kratkog videa (sličice lokalno).
- S41 Logo i ikone: vektorski model iz kataloga (ako postoji) + `vtracer`.
- S42 Slika → 3D model (GLB) ako postoji endpoint (po K06), prikaz u postojećem three.js pregledaču; inače „uskoro".

## Prihvatanje (sve mora da važi — ili upiši BLOKADA sa razlogom)
- Najmanje 15 recepata radi od kartice do rezultata (plaćeni DEMO bez ključa) sa fiksnom cenom (test cena).
- Brend kit se primenjuje u receptu i editoru.
- Nalepnice daju 9 fajlova 512×512 bez pozadine (test isecanja).
- `npm run typecheck`, `npm run lint`, `npm run test` prolaze (i `npx convex codegen` ako si dirao `convex/`).
- Sekcija „K15” je dopisana u `docs/CREA-PROGRESS.md` po šablonu iz pravila.
- Nijedan dev server nije ostao upaljen.
