# K05 — Stablo verzija, pre/posle i „Vrati”
Režim: **goal** · Effort: **high** · Sesija: **nova** · Model: Opus 5.5
Feature ID-jevi: S25, §4.3

Pre rada pročitaj: `.crea-run/rules.md` (obavezno, važi uvek), `docs/CREA-PLAN.md` (§4.3), `docs/CREA-PROGRESS.md`.
Ako `git status` pokazuje delimičan rad iz prekinutog pokušaja OVOG koraka, nastavi ga — ne kreći ispočetka. Ako je nešto iz ovog koraka već urađeno u ranijem koraku, nadogradi ga, ne dupliraj.

## Zadatak
- Widen `generationJobs`: `parentJobId`, `rootJobId` (opciono, bez migracije). Popuni ih u svim tokovima gde rad
  nastaje iz drugog rada (ponovna upotreba sa ulazom, produži/animiraj, izbor izvornog rada, lokalni alati iz K04).
- Upit za stablo jednog rada (sa proverom vlasništva) + čista logika gradnje stabla u `*Core.ts` sa testovima.
- U detalju rada: traka/stablo verzija (sličice), klizač pre/posle (`react-compare-slider`) kad su roditelj i dete slike,
  dugme „Vrati" (otvori roditelja kao aktivnog i ponudi ga kao ulaz).

## Prihvatanje (sve mora da važi — ili upiši BLOKADA sa razlogom)
- Svaki novi izveden rad ima roditelja; stablo se vidi u detalju rada.
- Pre/posle radi za slike; „Vrati" radi.
- Testovi za stablo i vlasništvo.
- `npm run typecheck`, `npm run lint`, `npm run test` prolaze (i `npx convex codegen` ako si dirao `convex/`).
- Sekcija „K05” je dopisana u `docs/CREA-PROGRESS.md` po šablonu iz pravila.
- Nijedan dev server nije ostao upaljen.
