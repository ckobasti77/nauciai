## Zadatak
Popravi SVE nalaze iz svoje revizije (K29) redom: KRITIČNO, pa VAŽNO, pa SITNO koliko stigneš. Za svaki nalaz:
popravka + test gde ima smisla. Zatim:
- pokreni `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`, `npm run check:frames`,
  `npm run check:corners` dok ne budu zeleni;
- napiši `docs/CREA-REPORT.md` — završni izveštaj za Jovana na srpskom: šta je Crea sada (po oblastima), tabela
  feature ID → stanje (gotovo / delimično / uskoro), šta je besplatno na uređaju, nove cene (iza flega) i kako se pale,
  šta mora ručno (ključevi, flegovi, deploy redosled iz `docs/studio-runbook.md`), poznata ograničenja, spisak
  snimaka ekrana, i predlog sledećih koraka.

## Prihvatanje (sve mora da važi — ili upiši BLOKADA sa razlogom)
- Svi KRITIČNI i VAŽNI nalazi su popravljeni ili obrazloženi.
- `npm run build`, `check:frames` i `check:corners` prolaze.
- `docs/CREA-REPORT.md` postoji i pokriva sve stavke iz zadatka.
- `npm run typecheck`, `npm run lint`, `npm run test` prolaze (i `npx convex codegen` ako si dirao `convex/`).
- Sekcija „K30” je dopisana u `docs/CREA-PROGRESS.md` po šablonu iz pravila.
- Nijedan dev server nije ostao upaljen.
