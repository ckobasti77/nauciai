## Zadatak
Tab „Napravi" u radionici Slika:
- S3 Auto čip u composeru (logika iz K07) sa rečenicom „zašto".
- S4 Probni list: 4–16 malih skica jeftinim modelom u mreži → izaberi → „Usavrši" premium modelom sa istim opisom.
- S5 Varijacije 1–4 na svakom modelu (paralelni poslovi gde model ne vraća više slika).
- S6 Pomoćnik za opis: srpski unos → precizan opis, obojen po delovima (ko · šta · stil · svetlo · kamera) uz kratko
  objašnjenje; jeftin LLM preko postojećeg Google ključa (praćenje troška, limit po korisniku; ≈0 kr). Mikrofon:
  Web Speech API (`sr-RS`) gde postoji, inače sakriven.
- S7 Slotovi Ko · Gde · Kako (tri slike) nad modelima sa više referenci — opis se sam sklopi.
- S8 Stilovi (~40, kartice sa ilustrativnim sličicama — NE generiši slike tokom runa; koristi SVG/CSS ili postojeće
  slike, upiši ODLUKU), „Moji stilovi", virtuelna kamera (telo, objektiv, žižna, blenda), paleta.
- S9 Crtaj i gledaj: platno + periodično slanje jeftinom brzom modelu (throttle, limit osvežavanja po sesiji, cena
  unapred) — DEMO bez ključa.
- S10 Skica → slika (platno ili fotka sveske).

## Prihvatanje (sve mora da važi — ili upiši BLOKADA sa razlogom)
- Sve funkcije su u UI-ju i rade (plaćeni delovi DEMO bez ključa); cena se vidi pre klika.
- Pomoćnik za opis ima limit i ne troši kredite korisnika (ili jasno 0 kr).
- Testovi za čistu logiku (sklapanje opisa, stilovi, kamera, throttle).
- `npm run typecheck`, `npm run lint`, `npm run test` prolaze (i `npx convex codegen` ako si dirao `convex/`).
- Sekcija „K13” je dopisana u `docs/CREA-PROGRESS.md` po šablonu iz pravila.
- Nijedan dev server nije ostao upaljen.
