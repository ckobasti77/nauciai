## Zadatak
- V10 Strip → film: priča → 3–8 kadrova kao strip u svesci (kartice uče vrste kadrova) → slika po kadru sa istim likom
  (S34) → animacija svakog → automatski u montažu (K19).
- V25 Titlovi na srpskom: postojeći `stt` (ili Whisper lokalno na desktopu), latinica/ćirilica (deterministička
  transliteracija + testovi), karaoke stilovi, utiskivanje kroz montažu.
- V26 Kratki klipovi iz dugog videa: transkript + jeftin LLM bira momente → lokalno sečenje + reframe 9:16 + titlovi.
- V27 Retro efekti (VHS, CRT, glič, termo, noćni vid, Nokia, pisaća mašina) kao WebGL šejderi + match-cut prelaz
  poravnat po licu.
- V28 Objašnjavajući video: lekcija/tekst → scene u stilu (tabla, štapići, papir, glina, pikseli) → jeftine slike +
  srpski glas + titlovi → lokalna animacija (Ken Burns/paralaksa) → MP4. Prikaži cenu (cilj ~20–50 kr po minutu).
- V31 Reklama za mali biznis: fotka proizvoda + dve rečenice → govorni oglas ili animacija proizvoda (recept).

## Prihvatanje (sve mora da važi — ili upiši BLOKADA sa razlogom)
- Strip pravi kadrove i spaja ih u montažu (plaćeni delovi DEMO).
- Titlovi u obe azbuke (test transliteracije), utisnuti u izvoz.
- Explainer daje MP4 sa glasom i titlovima (uz DEMO kad nema ključa).
- `npm run typecheck`, `npm run lint`, `npm run test` prolaze (i `npx convex codegen` ako si dirao `convex/`).
- Sekcija „K21” je dopisana u `docs/CREA-PROGRESS.md` po šablonu iz pravila.
- Nijedan dev server nije ostao upaljen.
