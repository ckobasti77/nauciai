### 0.2 Nalazi iz koda koji menjaju plan

1. **en rewrite.** `proxy.ts:127` ne rewrite-uje `en` putanje (vidi K01-2).
2. **Detalj rada se otvara regex-om nad javnom putanjom.** `components/app/studio-page.tsx:222` radi `pathname.match(new RegExp(`${basePath}/m/([^/]+)`))`, tj. poredi kanonski `basePath` (`/studio/app`) sa javnim `pathname`. Posle preimenovanja `/crea/app/m/<id>` ne bi otvarao detalj. Rešenje: porediti sa `parsePath(pathname).canonicalPath`.
3. **Ova mesta rade sama posle preimenovanja, samo ih treba proveriti:** `app/[locale]/(marketing)/auth/complete/page.tsx:38-39` (`goesToStudio`), `public-header.tsx:197` (`LIGHT_HERO_PATHS.includes(canonicalPath)`) i `lib/stripe.ts:118` (povratak sa Stripe-a). Sva tri prolaze kroz `withLocale` ili kanonsku putanju. Jedina posledica: stari linkovi sa `?next=/studio/...` ne preskaču onboarding korisničkog imena, što je prihvatljivo.
4. **`components/marketing/site-footer.tsx:75`** zove `withLocale(locale, "/uslovi-studio")`, tj. prosleđuje srpski slug umesto kanonskog. Zameniti sa `STUDIO_TERMS_PATH`. Dok se ne zameni, link štiti alias iz K01-1.

Pritom je `num_images` (do 4, `capabilities.maxImagesPerRun: 4`) `quantityParam` cene kod `gpt-image-2`, `gpt-image-15`, `seedream-45`, `seedream-5-lite` (fal) i `seedream-5-pro` (BytePlus). 9. **Drop ide u skriveni composer** ispod detalja, jer window listeneri ostaju aktivni. K03 gasi drop create-composera dok je detalj otvoren (AGENTS.md: jedna meta po ekranu).

### 1.1 `lib/routes.ts`

```ts
const SEGMENTS: Record<string, Record<Locale, string>> = {
  courses: { sr: "kursevi", en: "courses" },
  community: { sr: "zajednica", en: "community" },
  studio: { sr: "crea", en: "crea" },                       // bilo: studio/studio
  pricing: { sr: "pretplata", en: "pricing" },
  "privacy-policy": { sr: "politika-privatnosti", en: "privacy-policy" },
  "studio-terms": { sr: "uslovi-crea", en: "crea-terms" },  // bilo: uslovi-studio/studio-terms
  "3d": { sr: "3d", en: "3d" },
  mcp: { sr: "mcp", en: "mcp" },
};

/**
 * Stari javni slugovi koje i dalje PREPOZNAJEMO da bi ih proxy 308-ovao na nov oblik.
 * `toPublicPath` ih nikad ne proizvodi. Kanonski ključevi (`studio`, `studio-terms`) već
 * mapiraju sami na sebe, pa `/studio/*` i `/en/studio-terms` ne treba navoditi.
 */
const LEGACY_SLUGS: Record<string, string> = { "uslovi-studio": "studio-terms" };
// posle postojeće petlje nad SEGMENTS:
for (const [slug, canonical] of Object.entries(LEGACY_SLUGS)) SLUG_TO_CANONICAL[slug] ??= canonical;

/**
 * Da li proxy mora da rewrite-uje javnu putanju na internu. `sr` uvek (javni URL nema
 * prefiks); `en` samo kad se javni slug razlikuje od foldera (`/en/crea` → `/en/studio`).
 */
export function needsInternalRewrite(locale: Locale, canonicalPath: string, pathname: string): boolean {
  return internalPath(locale, canonicalPath) !== pathname;
}
```

### 1.2 `proxy.ts`

U `rewriteToInternal` (l. 126-133) prva linija postaje:

Ostalo se ne dira: prenos kolačića, auth i 307 na `/`. `isProtectedPath` i dalje štiti samo `/app/*`, pa `/crea/app` ostaje javna ruta sa prijavom u browseru, kao danas `/studio/app`.

### 1.3 `lib/security-headers.ts`

`FRAME_DENY_CANONICAL_SOURCES` dobija javne putanje Cree. Stare putanje ostaju, jer pokrivaju internu `/sr|/en/studio/...` posle rewrite-a i stari URL pre 308:
```ts
"/studio/app/:path*", "/studio/krediti/:path*",   // interna (posle rewrite-a)
"/crea/app/:path*",   "/crea/krediti/:path*",     // javna (sr bez prefiksa, en sa /en)
```
Komentar iznad liste glasi „kanonske I javne putanje".

Test (`lib/security-headers.test.ts:19-44`):
- DENY pogađa `/crea/app`, `/crea/app/m/abc`, `/en/crea/app`, `/crea/krediti`, `/en/crea/krediti` i `/sr/studio/app`.
- DENY ne pogađa `/crea`, `/en/crea` ni `/uslovi-crea`.
- Dodatni test: za svaku studio stavku, `toPublicPath("sr"|"en", "/studio/app")` mora da pogodi neko pravilo. To čuva od sledeće promene sluga.

### 2.4 Kako postojeće komponente ulaze u ljusku (i šta K03 mora da popravi)

1. `StudioPage` zadržava podatke i handlere; njegov JSX se premešta u slotove `CreaWorkshop`-a. Aktivna oblast dolazi iz `parseCreaShellState(searchParams)`, a `activeKind` za mrežu je oblast.
2. `StudioComposer` dobija opcioni prop `placement?: "floating" | "docked"`. Podrazumevano je `floating`, tj. današnje ponašanje. U `docked` položaju:
   - nema dugmeta za sklapanje;
   - pozicija je statična;
   - popoveri (izbor modela `sm:bottom-[calc(100%+12px)]` i čipovi) se otvaraju nadole.
3. Composer dobija ključ `key={`${activeModel.slug}:${area}:${mode}`}` (nalaz 0.2-8).
4. `generate(payload, model)` prima model eksplicitno (nalaz 0.2-7); detalj prosleđuje model posla.
5. `ModelPickerPanel` dobija `models` već filtrirane funkcijom `modelsForMode` i prop `lockedKind`, koji sakriva padajući izbor vrste. `?model=` se sinhronizuje i posle prvog rendera (danas samo na početku).
6. `StudioMediaGrid` računa broj kolona po širini kontejnera (opcioni `containerRef` u `useGridColumnCount`), jer je desna kolona uska.
7. Tri sitne popravke:
   - otvaranje i zatvaranje detalja čuva query string (nalaz 0.2-11);
   - drop u create-composer je ugašen dok je detalj otvoren (nalaz 0.2-9);
   - `ProjectPicker` dobija `"skip"` kad korisnik nije prijavljen.
8. Lekcijski tok mora da radi nepromenjeno: `?lessonId=&taskId=` iz `course-lab.tsx:698` na `/app/studio`. Pokriva se testom logike stanja i ručnom proverom.
9. Školski sidebar (`lib/sidebar-contexts.ts:108-129`): sekcije postaju tri oblasti (`?oblast=`), a `?kind=` ostaje čitljiv.
10. Režimi kojima treba drugi slot ili izbor izvora (`reference`, `layerize`, Omni `video`, `garment`) i dalje rade kao danas, tj. nedostupni su u UI-ju. Rešavaju ih K12, K18 i K20, ponovnom upotrebom `ReferenceSlots`, `FrameSlotPair`, `SourceJobPicker` i `ModeSwitcher` (nalaz 0.2-13).

### 3.7 CORS za platno (rizik koji K04 proverava prvi)

### 5.3 Izlaz kao ulaz: alias (K01-10)

`creaVersions.adoptOutputAsInput({ jobId, slot })` je mutacija iza `requireStudioAccess`:
1. Proverava da je posao moj, `done` i da ima `outputStorageId`, i da je `slot` `image`, `video` ili `audio` i odgovara vrsti.
2. Vraća postojeći alias red za taj `storageId`, ili upisuje nov `studioUploads { userId, storageId: job.outputStorageId, slot, bytes, mimeType, createdAt, sourceJobId: job._id }` bez `expiresAt`.
3. Vraća `{ storageId, slot, mime, size, url }` za `SlotFile`.
4. Za video i zvuk klijent zatim zove postojeću `studioActions.measureInputUpload`, koja radi nad redom u `studioUploads`.

- `studio.deleteJob` (l. 1811-1826): za alias red (`upload.sourceJobId`) briše se samo red, nikad blob.

### 5.4 Upit i čista logika

`creaVersions.getVersionTree({ jobId })` je query:
- vlasništvo se proverava kao u `getJobForDetail`; za tuđ posao vraća `null`;
- koren je `job.rootJobId ?? job._id`;
- čvorovi su koren (ako postoji) plus `by_root` `.take(100)`;
- čvor je `{ _id, parentJobId, derivation, kind, modelSlug, provider, status, createdAt, outputUrl }`. Potpisuju se samo slike; video i zvuk dobijaju poster ili ikonu.

`convex/creaVersionsCore.ts` sadrži `buildVersionTree(nodes, rootId)` → `{ root, children: Map, depth, pathTo(id) }`:
- čvor čiji je roditelj obrisan kači se na koren;
- ako je koren obrisan, najstariji čvor postaje koren;
- zaštita od ciklusa (`visited`), dubina najviše 20.

Testovi: oblik stabla, obrisani čvorovi, tuđ posao, granica od 100 čvorova.

## 8. Video motor (V24) i audio uređivač (A14): arhitektura

Detalje rade K17 i K24.

**Video motor.** Sve radi u browseru, iza `dynamic import`-a na `/crea` rutama.
- `mediabunny` (MPL-2.0; njegovi fajlovi se ne menjaju) radi demux i mux (MP4/WebM).
- WebCodecs `VideoDecoder`/`VideoEncoder` obrađuju kadrove.
- Kompozicija ide na `OffscreenCanvas` u Worker-u: 2D za sečenje, naslove i PiP, a WebGL2 za LUT, prelaze i retro šejdere (isti LUT-ovi kao S17).
- Zvuk se miksuje kroz `OfflineAudioContext`. Utišavanje muzike ispod govora je envelope iz VAD/RMS.
- Enkodiranje zvuka: AAC kroz WebCodecs, a MP3 kroz `@mediabunny/mp3-encoder` (LAME, LGPL) kao zaseban, nemenjan WASM.
- Model projekta je JSON:
  ```
  CreaTimeline { tracks[{ kind, clips[{ source: { jobId } | { localFileId }, in, out, start, speed, effects }] }], titles, transitions, audio }
  ```
  Nacrt je u IndexedDB-u. Opciono ide i u Convex kao mali JSON (do 100 KB), samo sa referencama na poslove, nikad sa medijem.
- Izvoz ide u `saveLocalResult` (video), sa `parentJobId` = glavni klip i `derivation: "montaza"`.
- Pregledač bez WebCodecs (npr. stariji Safari, Firefox Android) dobija jasnu poruku i nudi mu se samo pregled ili plaćene alternative.
- Dužina i rezolucija izvoza na telefonu su ograničene; brojeve određuje K17.
- V4 (poslednji kadar) koristi isti dekoder.

**Audio uređivač.**
- `wavesurfer.js` v8 sa regions plugin-om: talas, isecanje, više traka.
- Obrada ide kroz Web Audio graf: Gain, BiquadFilter EQ, DynamicsCompressor, Convolver sa proceduralnim IR-om, Delay.
- Biblioteke:
  - `signalsmith-stretch` (AudioWorklet): brzina i visina;
  - `@sapphi-red/web-noise-suppressor`: čišćenje;
  - Silero VAD (`@ricky0123/vad-web`): tišina;
  - `web-audio-beat-detector` i `meyda`: BPM i tonalitet.
- Glasnoća −14 LUFS po BS.1770 je čista funkcija u `lib/crea-loudness.ts` (K-težinski filteri i gating), sa testovima nad sintetičkim sinusima.
- Render ide kroz `OfflineAudioContext` u WAV (`wavefile`) ili MP3 (mediabunny). Rezultat ide u galeriju (0 kr).
- Projekat (trake, regioni, efekti) je JSON u IndexedDB-u.

| Rizik | Mera |
|---|---|

| Convex akcije i memorija (64 MB) | preuzimanja u delovima; nijedno kopiranje velikog bloba (alias, K01-10) |
| Telefoni bez WebGPU/WebCodecs | klase iz `lib/crea-device.ts`, poruka, mali model ili plaćeni put; nikad tihi pad |
| CORS storage-a za canvas | provera u K04, pre ostalih alata (3.7) |
| Licence | samo paketi iz §5, nikad iz §6; modeli sa licencom u registru (test); LGPL WASM (heic-to, LAME) zaseban i nemenjan; fajlovi mediabunny-a (MPL) se ne menjaju; CC0 izvor za svaki fajl; GSAP nikad za korisničke ključne kadrove |
| Novac | v2 iza flega i test identičnosti; `creditFactor` na poslu; noćna tura idempotentna i sa refundom po isteku; nagrade jednokratne sa ključem; besplatne probe pod globalnim plafonom; zatečen kvar sa `num_images` (K13) |
| Rast storage-a | lokalni limiti (minut, dan, bajtovi); retencija kao za plaćene radove; alias i pin umesto kopija; union-return briše odbijene blobove |
| Bundle | granice iz §9 i `check:bundle` |
| LiteSpeed MIME za samostalno hostovan WASM | ne hostovati u `public/`; inače `.htaccess` i `check:media` |
| Trošak tokom runa (dev ima pravi `GOOGLE_AI_API_KEY`) | testovi sa lažnim `fetch`-om; nijedan pravi batch ili LLM poziv u proverama |
| Proširenje unija (`queued`, `local`, `reward`, push `crea`, `leaderboardSourceType`) | spisak pogođenih fajlova u svakom koraku; `typecheck` ih hvata |
| Paralelni limit (2 javno) blokira varijacije i serije | server fan-out (6.8) ili red, odnosno noćna tura |
