# K10 — Mapa puta (staze i kursevi)

## Cilj
Staza i kurs dobijaju „mapu puta" kroz svesku (§2.3, K07 §3).

## Uradi
1. `components/igra/journey-map.tsx`: SVG putanja (ručno nacrtana linija) sa stanicama (moduli/kursevi), stanja
   urađeno / sledeće (pulsira nežno) / zaključano, „Ti si ovde" Robi nalepnica. GSAP DrawSVG iscrta urađeni deo.
2. Pozadina `scena.mapa-puta` kao tekstura iza putanje (fallback: papir + mreža).
3. Telefon: vertikalna putanja, horizontalni skrol nije dozvoljen.
4. Pristupačnost: lista stanica za čitač ekrana (ol), fokus po stanicama, reduced motion = statična mapa.
5. Povezivanje: `track-experience.tsx` i stranica kursa (pregled modula).
6. Izlog + snimci `docs/igra/snimci/K10-*.png`.
