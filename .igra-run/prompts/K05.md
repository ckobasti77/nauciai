# K05 — Gejmifikovani primitivi + izlog

## Cilj
Napravi sve primitive iz `docs/IGRA-PLAN.md` §2.3 kao **prezentacione komponente** i dev-only izlog gde se vide sa test podacima.

## Uradi
1. `components/igra/*`: XP traka, Pečat nivoa (`nivo.NN`), Nalepnica bedža (otključan / zaključan kao silueta /
   „uskoro"), Plamen niza, Rang čip (#N + medalja za top 3), Odometar, Misija dana, Trofejna polica, Kartica napretka
   (nivo + XP + niz u jednom), Lik (`<IgraLik lik="robi" poza="mase" />` preko IgraArt). Svaka: prazno / učitava se /
   reduced motion / obe teme / telefon.
2. `lib/igra-fixtures.ts`: realni test podaci (novi korisnik, aktivan, legenda).
3. Izlog: `app/[locale]/igra-izlog/page.tsx` — `notFound()` kad je `NODE_ENV === "production"`, `robots: noindex`,
   nije u sitemap-u. Sekcije po primitivu + dugmad za okidanje slavlja (nivo, bedž, kraj kursa) + 3D pehar.
4. Stil: sveska, premium, čisto (impeccable, design-taste-frontend, design-dna). Žuto je nagrada.
5. Snimci izloga (Playwright): 390 i 1440, obe teme → `docs/igra/snimci/K05-*.png`.
6. Testovi: formatiranje XP-a i nivoa, stanja bedža, a11y atributi (role, aria-label, aria-valuenow za traku).

## Prihvatanje
- Izlog radi lokalno, a u produkcionom buildu vraća 404.
- Svi primitivi imaju stanja iz tačke 1 i rade bez slika (fallback) i sa slikama.
- typecheck / lint / test / check:frames prolaze; sekcija K05 u progress-u.
