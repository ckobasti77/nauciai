## Uradi

2. Rezultat: „otkrivanje" (postojeći `reveal/*`) dobija marker i nalepnicu; prvi rad svake vrste = mini slavlje (igraSeen).
3. Greška generisanja: `lik.*.tuzan` + jasna poruka (postojeći tekstovi o povraćaju kredita ostaju tačni).
4. Reduced motion: sve statično, poruke ostaju.
5. Izlog + snimci `docs/igra/snimci/K16-*.png`.
