# K02 — Temelj: slike, tokeni, IgraArt

## Cilj
Sprovedi temelj iz plana K01 (ova sesija je nastavak K01): tokeni, registar slika i `<IgraArt>`, provera slika.

## Uradi
1. Tokeni iz K01 §1 u `app/globals.css` za obe teme (marker, nalepnica-senka, papir-tekstura, pečat…). Bez golih hex-ova u komponentama.
2. `lib/igra-art.ts`: tipizovan registar nad `public/brand/igra/manifest.json` (statički import JSON-a). Tip ID-ja je unija
   svih ID-jeva iz manifesta + planiranih iz koda. Funkcija `igraArt(id)` vraća `{ src, w, h, ready, alt }`.
3. `components/igra/igra-art.tsx`: `<IgraArt id size? priority? decorative? className />` — AVIF `<img>` sa width/height,
   lazy + decoding async (osim `priority`), alt po jeziku (iz `lib/i18n`), fallback kad `ready:false` ili onError
   (bez slomljene slike; fallback ne pomera layout).
4. `scripts/check-igra-assets.mjs` + `npm run check:igra`: lista ID-jeva iz koda kojih nema ili su `ready:false` (upozorenje, ne pad).
5. `.gitignore`: proveri da su `.igra-assets/`, `.igra-run/logs/` i `.igra-run/state.json` ignorisani.
6. Ako K01 odluči: `@gsap/react` (jedini unapred dozvoljen paket). Bez drugih paketa.
7. Testovi: `lib/igra-art.test.ts` (fallback, alt po jeziku, nepoznat ID).
8. Dodaj u `docs/igra/planovi/K01.md` ništa — plan ostaje kakav jeste; odluke idu u progress.

## Prihvatanje
- `<IgraArt id="lik.robi.mase" />` radi sa pravom slikom i sa fallback-om (ready:false) bez pomeranja layouta.
- `npm run check:igra` radi i ispisuje stanje.
- Tokeni rade u obe teme.
- typecheck / lint / test / check:frames prolaze; sekcija K02 je u `docs/IGRA-PROGRESS.md`.
