## `convex/providers/google.ts` + `lib/google-images.ts`
Običan `fetch`, bez SDK-a. `generativelanguage.googleapis.com`.
Modeli: `gemini-3.1-flash-image`, `gemini-3-pro-image`.
Ključ `process.env.GOOGLE_AI_API_KEY`; ako fali, jasna greška pre mreže.

Režimi: `text` i `image_multi` (1-10 ulaznih slika). Ulazne slike se čitaju iz
Convex storage-a; izaberi inline base64 ili File API i obrazloži u ODLUKE.

`resolution` i `aspect_ratio` su **parametri**, ne pinovane vrednosti - v4
katalog ih izlaže korisniku i cena ih prati preko `multipliers`.

## Sinhroni tok
`submitJob` za `mode: "sync"`: pozovi API -> dobij sliku -> obeleži posao
`done` -> zakaži `persistOutput`. Sve u istoj akciji. Greška -> `failJob`
(refundira). **Ne izmišljaj lažan webhook.** Posao nikad ne ulazi u `running`.

## Thinking tokeni
Google ih naplaćuje odvojeno ($3/M Flash, $12/M Pro) i to je u `addUsd` u
cenovnom pravilu. Ako API vrati stvarnu potrošnju, upiši je u
`generationJobs.actualCostUsd` - prvi put da imamo pravu maržu po poslu.
Ako stvarni thinking premaši `addUsd` za više od 50%, zaloguj upozorenje.
